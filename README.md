# Using Machine-Learned Potentials to Generate Transition-State Guesses for Open-Shell Hydrogen Atom Transfer Reactions

## Abstract
Locating the transition state (TS) of a chemical reaction with quantum mechanical methods requires an accurate initial structural guess which is usually obtained through an expensive, iterative ab initio search. Combining a machine-learned interatomic potential (MLIP) with a geodesic path algorithm have recently been proposed as a cheaper way to generate such guesses. The implementation we started from assumed closed-shell, singlet chemistry (a charge of 0 and a multiplicity of 1). This study adapts the current implementation by implementing an open-shell capable version of this geodesic-MLIP workflow. I will use this workflow for two radical hydrogen atom transfer (HAT) reactions: toluene reacting with tert-butoxyl (tBuO•) and tert-butylperoxyl (tBuOO•) radicals. I built the reactant and product structures in IQmol, and geodesic paths (resulting in 49 frames and 48 frames, respectively) were evaluated with Meta’s eSEN MLIP model. The original pipeline only supported the default values of a charge of 0 and a multiplicity of 1. I modified the configuration code to accept arbitrary charge and multiplicity. We took the highest-energy frame from each path as the initial guess for the transition state and refined with density functional theory (DFT) in ORCA 6.1.1 using the ChemRefine pipeline. Both optimizations converged to first-order saddle points, each with a single imaginary vibrational frequency, and intrinsic reaction coordinate (IRC) calculations confirmed that each TS connects a reactant-like and a product-like complex. This suggests that our adapted MLIP and geodesic workflow can provide useful TS guesses for DFT optimization of HAT reactions.
